# Startulize — Elite Digital Engineering & Growth Agency

Startulize is a production-ready, high-converting digital agency landing page built with **Next.js 14 (App Router)**, **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## 🚀 Features

- **Dark-Mode Aesthetic**: Engineered with a high-contrast monochromatic base (`zinc-950`), glowing emerald/teal/cyan accents, and glassmorphic card overlays.
- **Conversion-First Architecture**: Sticky navigation with live availability badge, prominent Discovery Call CTAs, and interactive consultation modal.
- **7 Core Service Offerings**:
  1. WordPress & Headless Next.js
  2. Webflow Development & 3D Web
  3. Wix Studio Modern Solutions
  4. Data-Driven Technical SEO
  5. Brand Identity & Visual Systems
  6. Meta Ads & Paid Social Funnels
  7. Google Ads & Performance Max
- **Dynamic Animations**: Staggered hero text reveals, infinite horizontal partner marquee, scroll-triggered card entrances, and smooth collapsible FAQ accordion.
- **SEO & Data Architecture**: Comprehensive OpenGraph/Twitter card metadata and dynamically injected LocalBusiness / ProfessionalService JSON-LD schema.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Build for Production
```bash
npm run build
npm run start
```
